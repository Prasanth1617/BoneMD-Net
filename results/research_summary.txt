Bone Disorder Diagnosis Using X-ray and CT Images.

  Train: 190
  Validation: 41
  Test: 41

Split is fixed with random seed 42.

INPUT PREPROCESSING
-------------------
X-ray:
  - AP and lateral views
  - MONOCHROME1 inversion handled
  - 1st-99th percentile intensity normalization
  - aspect-ratio-preserving resize
  - zero padding
  - final size: 224 x 224

CT:
  - PRIMARY + AXIAL reconstruction
  - HU conversion
  - reconstruction selection by spatial resolution/coverage
  - resampling to 1.0 x 1.0 x 2.5 mm
  - center crop/padding
  - final volume: 192 x 320 x 320

IMPORTANT INTERPRETATION
------------------------
The teacher currently provides the strongest measured test performance.

The student uses substantially fewer parameters, but its current test
performance is lower than the teacher.

Knowledge distillation improves test accuracy relative to the supervised
student baseline (46.34% vs 43.90%), but its test macro F1 is lower
(25.87% vs 28.28%).

The X-ray-only and CT-only experiments show class-collapse behavior and
should be discussed as modality ablations rather than evidence of a
universal modality ranking.

AP-only and lateral-only models both predicted only the Normal class on
the locked test set.

The test set was used only after model selection and was not used for
hyperparameter tuning.

LIMITATIONS
-----------
- Small multimodal cohort after strict matching: 272 patients.
- Test set contains only 41 patients.
- Class imbalance remains present.
- Current student performance does not yet match teacher performance.
- Several ablation models exhibit minority-class collapse.
- External validation has not yet been performed.
- Clinical deployment should not be claimed from the current experiments.
