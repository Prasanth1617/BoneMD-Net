IMPORTANT INTERPRETATION
------------------------
Among the evaluated configurations, the final normalized multimodal
teacher achieved the highest recorded test accuracy in the current
experiment set:

  Test accuracy: 75.61%
  Test macro F1: 75.43%

The final 75.61% result is a teacher-model result. It was trained using
weighted cross-entropy with label smoothing and cosine learning-rate
scheduling. It was not produced by the Student + KD training procedure.

The student uses substantially fewer parameters than the teacher:
1,108,038 versus 6,105,603 parameters.

The current Student + KD configuration did not match the predictive
performance of the final teacher:

  Student + KD test accuracy: 46.34%
  Final teacher test accuracy: 75.61%

The Student + KD experiment achieved higher test accuracy than the
supervised student baseline (46.34% vs 43.90%), while its test macro F1
was lower (25.87% vs 28.28%).

The X-ray-only and CT-only experiments should be treated as modality
ablations. Their results should not be interpreted as a universal
ranking of modalities.

AP-only and lateral-only models exhibited minority-class collapse on
the locked test set.

The final checkpoint was selected using validation performance. The
test set was used only for final evaluation and was not used for
hyperparameter tuning or model selection.

The final training run showed substantial training-set fitting while
validation performance remained lower, indicating overfitting. The
checkpoint from epoch 195 was retained because it provided the selected
validation performance.


LIMITATIONS
-----------
- Small multimodal cohort after strict matching: 272 patients.
- Test set contains only 41 patients.
- Class imbalance remains present.
- Current student performance does not yet match teacher performance.
- Several ablation models exhibit minority-class collapse.
- External validation has not yet been performed.
- Clinical deployment should not be claimed from the current
  experiments.
- Model probabilities should not be interpreted as clinical certainty.
